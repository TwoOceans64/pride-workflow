Pride Workflow
A Next.js frontend for submitting SACCO loan requests, integrated with an n8n workflow that automates loan review, sends email notifications, and logs data to Google Sheets.

This prototype was designed to give Africans with low credit scores or no business bank account a fairer chance at credit. Applicants submit salary and loan purpose, and the system runs AI‑driven risk and guardian assessments before human review, adding transparency and improving trust in the lending process.

🚀 Features
Next.js frontend for loan request submission

n8n workflow integration for automated loan review

Email notifications to applicants and reviewers

Google Sheets logging for transparent record‑keeping

AI‑driven risk & guardian assessments before human review

🛠️ Tech Stack
Frontend: Next.js (TypeScript)

Workflow Automation: n8n

Data Logging: Google Sheets API

Notifications: Email integration

AI Models: Groq Versatile & LLaMA for risk assessment

📦 Getting Started
Clone the repo:

bash
git clone https://github.com/TwoOceans64/pride-workflow.git
cd pride-workflow
Install dependencies:

bash
npm install
Run the development server:

bash
npm run dev
Open http://localhost:3000 in your browser.

🌍 Impact
This project changes the loan application process by:

Adding transparency through automated assessments

Giving underserved applicants (farmers, vendors, small business owners) a fairer chance at credit

Reducing bias in traditional loan reviews

Providing a scalable model for SACCOs and community lenders
